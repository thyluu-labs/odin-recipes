# Recipes Project

This is my first HTML project from The Odin Project. I will build a basic recipe website using HTML.

The website will contain a homepage with links to several recipes. Each recipe page will include information such as ingredients, instructions, and images.

Skills Demonstrated

By completing this project, I will demonstrate my ability to:

Create and structure HTML documents
Use headings, paragraphs, lists, links, and images
Create multiple pages and connect them with links
Organize files and folders for a website
Use Git and GitHub to track and publish my work
